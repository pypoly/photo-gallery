Веб-приложение для загрузки, хранения и организации фотографий по альбомам.

### Возможности:
- Загрузка и хранение фотографий
- Создание, редактирование и удаление альбомов
- Распределение фото по альбомам
- Автоматическое создание тамбнейлов для фото и альбомов
- Парсинг EXIF данных из фото
- Сортировка по дате создания снимка
- Личный кабинет пользователя

### Технологии:
- Backend: Python, Django
- База данных: PostgreSQL
- Фоновые задачи: Celery, Redis
- Инфраструктура: Docker, Nginx

### Запуск:
```shell
git clone https://github.com/pypoly/photo-gallery.git
cd photo-gallery
docker compose up --build
```
